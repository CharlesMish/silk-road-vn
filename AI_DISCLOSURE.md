# Generative AI disclosure

Silk Road was created as a human-directed vibe-coding project. Generative AI assisted with portions of:

- code and implementation;
- visual asset generation and refinement;
- writing and dialogue iteration; and
- interface and creative-direction exploration.

The creator set the direction, selected and rejected outputs, revised and integrated the material, performed playtesting and release review, and recorded the motif cues used in the game.

This disclosure is intentionally concise. The complete internal provenance and review archive is not part of the public distribution.
