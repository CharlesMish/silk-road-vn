# Silk Road

**Mistress Lan’s final road — a short browser-based trade visual novel.**

[Play Silk Road in your browser](https://CharlesMish.github.io/silk-road-vn/)

Keep the ledger honest. Carry the trade west. Learn what Lan means to leave behind. The journey crosses four cities in one sitting and resolves through three possible outcomes.

## Play

- Estimated length: **5–10 minutes**
- Platform: modern desktop or mobile browser
- Installation: none
- Audio begins after the first click, tap, or keypress because browsers block unsolicited playback.
- Progress and audio preferences are stored only in the browser’s local storage.

The published game is a single self-contained HTML file. It has no server component, account system, analytics, or external runtime dependencies.

## About the project

Silk Road was made as a tightly directed human–AI vibe-coding project. Generative AI assisted with portions of the code, visual production, writing, and design iteration; the creator directed, selected, edited, integrated, tested, and recorded the game’s motif cues.

This repository contains the distributable browser build and publication infrastructure rather than the complete internal production archive.
