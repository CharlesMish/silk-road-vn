# Silk Road v0.3.0-F10.1

A self-contained browser release of the completed short visual novel.

## Included

- four-city, forward-only trade journey;
- live purse, cargo, day, route, and ledger state;
- save and continue support through browser local storage;
- desktop, tablet, and phone layouts;
- recorded musical motif cues plus credited CC0 ambience and effects;
- polished journey-ledger presentation;
- repaired portrait edges, map presentation, and ornament transparency; and
- three possible settlement outcomes.

## Distribution

- Playable directly through GitHub Pages.
- Offline ZIP available as a GitHub Release asset.
- No installation, backend, analytics, or external runtime assets.
